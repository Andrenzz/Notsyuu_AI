PRIVASI & PERSONALISASI

Kamu yang memilih.

Mesin AI lokal

Belum ada model

Impor model teks .litertlm yang kompatibel dengan LiteRT-LM. Mulai dari model kecil sekitar 1B parameter. File model terpisah dari APK, maksimum 2,2 GB.

Akses internet

Pertanyaan umum dapat mencari cuplikan web dan menampilkan sumber. Hanya teks pertanyaan yang dikirim ke penyedia pencarian, bukan isi layar, profil, atau notifikasi. Matikan untuk mode lokal. Jika suara offline tidak tersedia, mode internet mengizinkan layanan suara HP yang dapat mengirim audio ke penyedianya.

Contoh: “Cari di internet cara merawat tanaman”. Tanpa model lokal, hasil pencarian ditampilkan langsung; ringkasan AI memerlukan model.

Suara Notsyuu

Pilih suara pria offline yang paling cocok. Nada dibuat sedikit rendah dan tenang. Ketersediaan suara pria bergantung pada mesin suara HP.

Izin perangkat

Aktifkan hanya yang dibutuhkan. Jika Android menampilkan pengaturan dibatasi, tinjau izin melalui info aplikasi. Layar terlindungi tidak dapat dibaca.

Profil untuk formulir

Simpan nama dan alamat yang ingin kamu gunakan. Hindari sandi, PIN, OTP, dan data kartu. Isian memerlukan konfirmasi.

Folder pencarian

Belum ada folder yang dipilih.

Cari berdasarkan nama: “Cari file laporan”. Isi file tidak dibaca.

Akses aplikasi

Semua aplikasi dengan halaman peluncur dapat dibuka. Pilih izin tambahan untuk membaca layar dan menyimpan notifikasinya.
